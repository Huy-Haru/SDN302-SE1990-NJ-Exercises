# Exercise 2: ES6 Todo List

Run with Node.js:

```sh
cd EX2
npm start
```

Choose `1` to add a task, `2` to display tasks, `3` to mark a task
completed using its displayed index, or `4` to exit. Tasks stay in memory
until the application exits. `[ ]` means incomplete; `[X]` means completed.

The exercise uses classes, ES modules, arrow functions, a Promise with
async/await, template literals, and destructuring in `TodoList.js`.
