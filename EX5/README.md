# Exercise 5: A simple Express server

```sh
cd EX5
npm ci
npm start
```

Open http://localhost:3000 to see `Hello, Express!` as requested in step 4.
The code example's route http://localhost:3000/Hello returns `Hello, World!`.
Both routes return HTTP 200. Unknown routes return HTTP 404.

You can also start the server with `node server.js`. Stop it with Ctrl+C.
The default port is 3000; set the `PORT` environment variable to change it.
